## Permitted summary

ACE's Token-Bleed R5 reference application separates a generic assessment and two
governed-versus-full claims that were accepted from governed-versus-lexical value and routing-miss
claims that were rejected under a frozen cost rule. It demonstrates claim-scoped retained-evidence
assessment. It does not independently reproduce the local collection, validate the private raw
report, certify a deployment, or establish a cross-model result.

## Publication angles

### Method reader

**Working thesis:** A single experiment verdict is often too coarse. Independent claims need
independent decision scopes so an accepted narrow comparison cannot hide a rejected economic one.

### Practitioner reader

**Working thesis:** Retain the contract and trial evidence before a result exists, because the
evidence needs permission to disagree with the headline.

### Technical reader

**Working thesis:** The benchmark runner and the evidence assessor are deliberately separate:
one measures a workload, the other determines which retained claims the record supports.

## Pre-publication gate

1. Link to the immutable R5 release and ACE reference application.
2. State the accepted and rejected claim scopes together.
3. State that ACE assesses supplied retained evidence only.
4. Do not call an ACE verdict a replication, certification, or production-performance claim.
