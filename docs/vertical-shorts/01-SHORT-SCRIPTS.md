# ACE evidence-literacy vertical-short scripts

All lines are on-screen captions, designed for muted autoplay. Keep captions under about ten words
per beat. Generated visual assets must not contain text. Overlay exact captions during assembly.

## `ace-contract-before-run`

**Hook:** A benchmark result is not evidence by itself.

| Beat | Caption | Visual direction |
|---|---|---|
| B0 | Start with a frozen contract. | A clean contract page locks into place. |
| B1 | State the question before the run. | One bounded question appears as an abstract line. |
| B2 | Name each claim separately. | Several small claim cards separate from a single headline. |
| B3 | Set the acceptance conditions. | A preflight checklist resolves into a sealed boundary. |
| B4 | Then collect the evidence. | A neutral runner icon deposits records into a ledger. |
| B5 | Keep the original contract beside it. | Contract and evidence ledger align side by side. |
| B6 | Scope follows what evidence earned. | A claim card stops at a clearly marked boundary. |
| B7 | Freeze first. Interpret second. | The contract becomes a stable frame around the result. |

**End card:** A benchmark result is not evidence by itself.

## `ace-retain-the-evidence`

**Hook:** If the evidence cannot travel, neither can the claim.

| Beat | Caption | Visual direction |
|---|---|---|
| B0 | Retain the contract. | Sealed contract enters a numbered ledger. |
| B1 | Retain the preflight. | Checklist card joins the ledger. |
| B2 | Retain the trial evidence. | Structured rows animate into a compact evidence file. |
| B3 | Render a decision pack. | Claim cards and verdict fields assemble from records. |
| B4 | Bind artifacts with hashes. | Hash ribbon connects each artifact without implying blockchain. |
| B5 | Keep the collection boundary visible. | Transparent wall separates runner from ACE assessment. |
| B6 | A hash identifies an artifact. | Hash label attaches to decision pack. |
| B7 | It does not attest collection. | Boundary wall remains explicit and calm. |

**End card:** Retain the contract. Scope each claim.

## `ace-claim-by-claim`

**Hook:** One run can support and reject different claims.

| Beat | Caption | Visual direction |
|---|---|---|
| B0 | R5 is a reference application. | Reference Application chip on an abstract experiment ledger. |
| B1 | Compare governed context to raw context. | Two neutral context packets align for comparison. |
| B2 | Those scoped claims were accepted. | Green accepted cards, labeled governed-versus-full only. |
| B3 | Compare governed context to lexical filtering. | A third, smaller lexical packet appears as a legitimate baseline. |
| B4 | The frozen cost condition mattered. | A clearly labeled 3x prompt-cost boundary line appears. |
| B5 | Those scoped claims were rejected. | Amber rejected cards, labeled governed-versus-lexical only. |
| B6 | Rejected does not erase accepted. | Both result groups remain visible, separate and intact. |
| B7 | Scope every conclusion. | Cards resolve into distinct, bounded claim lanes. |

**End card:** A result is only as broad as its evidence.

## `ace-verification-is-not-attestation`

**Hook:** Rechecking a packet is not certifying a run.

| Beat | Caption | Visual direction |
|---|---|---|
| B0 | A public packet can be rechecked. | Public packet icon opens beside a verification mark. |
| B1 | Verify hashes and structure. | Hash ribbon and evidence rows align. |
| B2 | Regenerate the decision record. | Decision pack reconstructs from retained public evidence. |
| B3 | Confirm the declared verdict shape. | Accepted and rejected scoped cards reappear. |
| B4 | ACE did not run the benchmark. | Boundary wall separates ACE from the runner. |
| B5 | ACE did not collect the raw report. | Private raw-report icon stays behind a privacy boundary. |
| B6 | Recheck is not attestation. | Verification mark changes into a bounded “recheck” label. |
| B7 | Keep the distinction explicit. | Clean final split between assessment and collection. |

**End card:** Recheck the evidence. Do not overstate it.
